# Skill example corpus

Every directory here is a **real config fragment** that
`validate_config` / `validate_xml` must pass.

## Contract

- Provenance and licence recorded in this file.
- No confidential configs. `find_examples` ships snippets to the host
  model. Private trees are gauntlet *targets* by absolute path, never
  corpus entries.
- Placeholder directories (no XML yet) must contain `PLACEHOLDER.md`
  so tests skip them instead of failing CI.
